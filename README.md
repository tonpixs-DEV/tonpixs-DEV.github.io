# นับแต้มพิกเคิลบอล

เว็บแอปนับแต้มพิกเคิลบอล (คู่/เดี่ยว, เสิร์ฟ 1-2, เล่นถึง 11/15/21) ไฟล์เดียว ไม่ต้องติดตั้งอะไร

## วิธีขึ้น GitHub Pages
1. สร้าง repository ใหม่ที่ github.com (เช่นชื่อ `pickleball`) แล้วเลือก Public
2. กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (ทุกไฟล์ในชุด) ไปวาง กด Commit
3. ไปที่ Settings > Pages > Source เลือก "Deploy from a branch" > Branch `main` โฟลเดอร์ `/ (root)` > Save
4. รอประมาณ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/pickleball/`

## ใช้เป็นแอปบนมือถือ
เปิดลิงก์ในเบราว์เซอร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
